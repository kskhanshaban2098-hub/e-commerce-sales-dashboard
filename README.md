# 📊 E-Commerce Sales Dashboard

## 📌 Project Overview

This project presents an interactive **E-Commerce Sales Dashboard** designed to analyze sales performance and generate meaningful business insights from e-commerce data.

The dashboard focuses on key metrics, sales trends, product performance, customer behavior, and regional analysis.

## 🎯 Project Objectives

* Analyze overall sales performance.
* Track important business KPIs.
* Identify top-performing products and categories.
* Analyze sales and profit trends.
* Understand customer and regional performance.
* Create interactive and easy-to-understand visualizations.

## 📊 Key Features

* KPI-based sales analysis
* Sales and profit trend analysis
* Product and category performance
* Regional sales analysis
* Customer and payment insights
* Interactive filters and visualizations
* Business-focused dashboard design

## 🛠️ Tools & Technologies

* **Power BI**
* **DAX**
* **Power Query**
* **Excel**
* **Data Visualization**

## 📈 Dashboard Analysis

The dashboard provides insights into:

* Total Sales
* Total Profit
* Quantity Sold
* Sales Trends
* Product Categories
* Regional Performance
* Customer Segments
* Payment Methods

## 🚀 How to Use

1. Download or clone the repository.
2. Open the Power BI `.pbix` file using **Power BI Desktop**.
3. Refresh the data if required.
4. Use the available filters and visuals to explore the dashboard.
5. Interact with the charts to analyze different business dimensions.
